Dynamic Data Grid

About

A product explorer that retrieves product information from an online API and displays it dynamically.

Features

- Fetch product data from an API
- Search products by name
- Filter products by category
- Sort products by price
- Responsive product grid
- Loading and error messages

Technologies Used

- HTML5
- CSS3
- JavaScript
- Fake Store API

How to Run

1. Download or clone this repository.
2. Open "index.html" in a browser.
3. Ensure an internet connection is available.

Project Purpose

To learn API integration, asynchronous JavaScript, and dynamic DOM manipulation.
